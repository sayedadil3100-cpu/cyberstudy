# Cyberstudy

A BCA cybersecurity learning dashboard by Syed Adil.

- Twelve chapters from basic to advanced, with summaries and self-checks
- Interactive cybersecurity career roles
- Four-question practice sessions, quiz mode and wrong-answer review
- Progress stored in the current browser

## GitHub Pages

Publish the main branch from the repository root in Settings > Pages.
The site is buildless: index.html loads the CSS and JavaScript beside it.

Progress is stored per website address. Existing progress on the original Sites address will not automatically transfer to GitHub Pages.
